💻 2. How to Run Without Antigravity IDE

If Antigravity IDE is not installed on your other computer or reviewer device, you can run the project in ANY standard editor or terminal using standard Node.js and web browsers (Chrome, Edge, Firefox, Safari):

Prerequisite: Only Node.js is required! If Node.js is not yet installed on the target machine, download it from https://nodejs.org (Version 18 or 20+ Recommended).
  1. Extract the ZIP archive: Unzip AGRISETU_FULL_PROJECT.zip into any folder.
  2. Open Terminal / Command Prompt: Press Win + R, type powershell or cmd, and navigate into the folder:
    cd path\to\AGRISETU_PROJECT
  3. Install Dependencies:
    npm install
  4. Start Development Server:
    npm run dev
  5. Open Web App in Browser: Click or navigate to:
    http://localhost:5173
